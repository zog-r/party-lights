# Party Lights for Gemini

Read `AGENTS.md` in this folder. To help a host make an event app, follow `skills/party-lights/SKILL.md` and start with `node scripts/next.js`. `AGENTS.md` lists the other skills and the commands. The skill files are the single source of truth.

Gemini-specific notes:
- With Gemini CLI you have a shell and can write files, so run the skills as written.
- In the Gemini web app you have neither. Use `docs/chat-only.md`.
